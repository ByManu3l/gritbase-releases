# GritBase Desktop — Releases

Instaladores oficiales de **GritBase** para escritorio (Windows) y el canal de
**actualización automática** de la app.

- El código fuente de GritBase es privado; este repositorio solo publica los
  binarios firmados y el manifiesto `latest.json` que la app instalada consulta
  para actualizarse sola.
- Cada release incluye la firma criptográfica (`.sig`) verificada por la app
  antes de instalar cualquier actualización — un binario alterado no se instala.

**Instalación:** descarga el `.exe` (NSIS) del release más reciente.
Las versiones siguientes se instalan solas: la app te avisa y se actualiza.
